Elemente pentru organizarea continutului text (text content elements)

Elementul paragraf <p>

Elementul paragraf este un element semantic care reprezinta de obicei un paragraf de text. Poate contine grupa elemente cu continut inrudit: imagini, text, elementele dintr-un formular. Un paragraf este delimitat implicit de alte elemente printr-o linie libera.

Elementul <div>

Elementul div este un container generic. Contine de obicei alte elemente , dar poate contine si text (nu este recomandat).
Poate fi utilizat pentru a stiliza mai usor elementele pe care le grupeaza.
Nu este delimitat implicit de alte elemente.

Elementul semantic <backquote>

The blockquote HTML element indicates that the enclosed text is an extended quotation. Usually, this is rendered visually by indentation (see Notes for how to change it). A URL for the source of the quotation may be given using the cite attribute, while a text representation of the source can be given using the cite element.

—MDN, The Block Quotation element

Elemente care pot sa apara inline in cadrul textului

Elemente non-semantice

Elementul ancora <a>: In cadrul textului pot sa apara elemente ancora, care creeaza un hyperlink catre alte resurse: vezi documentatia HTML pentru mai multe informatii . O ancora poate sa apara oriunde in interiorul unui text.

Elementul boldface <b>: este folosit pentu a atrage atentia asupra unei parti de text. Contintul este afisat de browsere cu text ingrosat.

Elementul abreviere <abbr> : acesta este folosit pt. a marca o abreviere, dar nu este stilizat de browser in mod implicit.

Elementul <u>:evidentiaza text care trebuie subliniat : aceasta este o greseala care trebuie corectata.

Elemente semantice

Elementul <strong> : Acesta este un element semantic folosit pentru a marca importanta unui continut . Este afisat precum elementul <b>.

Elementul <mark>: este folosit pentru a evidentia o parte de text intr-un anumit context. Trebuie sa tineti minte acest fragment

Elementul <cite> : este folosit pentru a marka titlul unei lucrari citate. Am preluat definitia din MDN HTML elements.

Elementul <code>: este folosit pentru a indica faptul ca textul care urmeaza este un fragment de cod. De exemplu console.log(str) este un fragment de cod in limbajul javascript

Elementul <sample>: este folosit pentru a evidentia output produs de un program, de exemplu 404 Not Found

Elementul <dfn>: este folosit pentru a marca un termen care este definit. Un URI este ...

Elementul <em> : este folosit pentru evidentia o sectiune de text , de exemplu aceasta parte de text.

Elementul <q> : este folosit pentru a marca text citat: Acesta este un citat din [Sursa citata]

Elementul <s>: reprezinta text taiat de o linie, pentru a marca continut care nu mai este valabil, relevant. De exemplu aceasta metoda nu mai este folosita

Element <var>: este folosit pentru a marca o variabila matematica, de exemplu x si y.

Elementele <sub> si <sup>: marcheaza text ce trebuie folosit ca indice, respectiv exponent: X23 , X23

Elementul <kbd>: este folosit pentru a reprezenta elemente ale tastaturii, de exemplu Ctrl + Shift.

Elementul <small>: este folosit pentru a reprezenta comentarii secundare si text scris cu caractere mici, precum drepturi de autor , de exemplu copyright.
